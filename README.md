# 💬 MERN Real-Time Chat Application

A full-stack real-time chatting application built using the **MERN Stack**.  
Users can create an account, log in securely, see other users, and exchange messages in real time.

## 🚀 Features

- 🔐 User Signup & Login
- 🔑 JWT Authentication
- 🍪 Secure Cookie-based Authentication
- 💬 Real-Time Messaging
- ⚡ Socket.IO Integration
- 👥 User List / Other Users
- 📨 Send and Receive Messages Instantly
- 🗄️ MongoDB Database
- 🔒 Password Encryption
- 📱 Responsive UI
- 🎨 Modern UI using Tailwind CSS
- 🚪 Logout Functionality
- 🛡️ Protected Routes

## 🛠️ Tech Stack

### Frontend

- React.js
- Redux Toolkit
- React Router DOM
- Axios
- Tailwind CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
